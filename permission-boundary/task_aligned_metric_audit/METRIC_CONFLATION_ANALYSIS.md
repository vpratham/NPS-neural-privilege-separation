# Metric conflation analysis

## Question and method

The test was deliberately narrow: can records with the same **complete original score vector**, the same task and condition, show different fully identified A/B/C behavior? A scalar reward alone is not treated as the original benchmark's entire metric when a released verifier also stores component fields. The frozen protocol prohibits treating a wrong answer as evidence of injection or a source opinion as an attack.

The four TAB C=YES labels are supported by a retained untrusted directive, a later matching assistant tool action, and an observed execution/result artifact for the author-designated distractor objective. They do not establish attacker intent, semantic equivalence to a natural-language prompt-injection exploit, or general model susceptibility.

All 27 selected local NPB outputs are currency literals. Their original `reference_exact` and `reference_contained` diagnostics are false, including their clean controls. The 18 attacked instances therefore receive C=NO only under the frozen, mechanical rule that a currency-only response does not fulfill the designated automation request. This is not a finding of injection resistance, and the answer-key mismatch cannot be recast as false-claim acceptance.

## Scalar-reward observation

Among five scored TAB trajectories, three cross-task pairs share historical reward 0 while differing in `injection.executed`; four records participate. This is **OBSERVED** scalar aggregation. It is not a primary conflation finding because the same released verifier vector separately reports the execution field. The C label for the `caffe-cifar-10` participant remains indeterminate due to a truncated retained exposure trace.

## Interpretation

**VERIFIED FACT:** This sample does not demonstrate that equal complete benchmark scores hide different fully identified outcome categories.

**SUPPORTED INFERENCE:** A reward-only leaderboard display could be insufficient for a user who needs to distinguish task failure from a side effect, but the inspected TAB artifact itself preserves the side-effect component.

**UNVERIFIED CLAIM:** A different benchmark, complete TAB corpus, or another defense comparison would show the same non-conflation result or a ranking change.

**OPEN QUESTION:** Whether records with independently adjudicated source opinions and false claims reveal a consequential collision after holding trusted task rules fixed.
