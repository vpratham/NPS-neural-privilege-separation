**UNVERIFIED CLAIM:** A benchmark-wide ranking changes when decomposed into A/B/C; any existing defense fails to distinguish source opinions, misinformation, and redirection; or a new benchmark/neural architecture is warranted.

It should begin only if the records and scorer can be authenticated; it does not justify new model evaluation yet.
