# Permission-boundary package

This package implements host-assigned document visibility, per-layer/cached-step attention masks, protected policy memory, buffered generation, and the local Q&A pilot. It also provides a provider-independent per-instance capability gate separating evidence reads, evidence disclosure and action proposals; see [`CAPABILITY_BOUNDARY.md`](CAPABILITY_BOUNDARY.md). Start with [`READ_PERMISSIONS.md`](READ_PERMISSIONS.md) for the model/runtime security contract, then [`DOCUMENT_QA.md`](DOCUMENT_QA.md) for setup and use. Neither path claims that readable evidence cannot change model behavior.
