# Permission-boundary package

This package implements host-assigned document visibility, per-layer/cached-step attention masks, protected policy memory, buffered generation, and the local Q&A pilot. Start with [`READ_PERMISSIONS.md`](READ_PERMISSIONS.md) for the exact security contract, then [`DOCUMENT_QA.md`](DOCUMENT_QA.md) for setup and use. The only supported claim is scoped denied-source noninterference under the documented model/runtime assumptions.
